# Support

## Read this first

This project is **pre-alpha**. Package APIs will change, nothing is published to npm from this
repository yet, and there is no support commitment. If you are evaluating it to run a term of
teaching on, the honest answer is: not yet. The [README](README.md#status) says what is and is
not in place.

## Where to go

| You want to | Go to |
|---|---|
| Ask how to use something | [Discussions](https://github.com/BingooAI/bingoo-open/discussions) |
| Report something broken | [Open a bug](https://github.com/BingooAI/bingoo-open/issues/new/choose) |
| Propose a feature or a model change | [Discussions](https://github.com/BingooAI/bingoo-open/discussions) first, not an issue — see [CONTRIBUTING](CONTRIBUTING.md#before-you-start) |
| Understand why something is designed as it is | The doc comment on the type, then [`docs/adr/`](docs/adr/) |
| Report a vulnerability | [SECURITY.md](SECURITY.md) — privately, never a public issue |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## What makes a question easy to answer

The smallest input that shows the problem, what you expected, and what happened instead. A
failing test is the most useful bug report there is — it removes every round trip about what
you meant.

If it is about setup, include your Node and pnpm versions and which providers you configured.
Most setup problems turn out to be a capability with no adapter configured.

## Response times

None to promise. This is a small team and support is best-effort, with one exception:
**security reports are acknowledged within 3 working days** (see [SECURITY.md](SECURITY.md)).

If something sits unanswered for a week, chase it. That means it was missed, not ignored.

## Commercial support

None offered today. If that changes it will be said here plainly, and it will not change what
the open repository can do — what we run and what you can self-host stay at parity.
